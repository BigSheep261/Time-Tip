# TimeTip 页面风格与动效规范

## 设计方向

TimeTip 采用苹果风格的极简桌面界面：内容优先、留白充足、层级克制。页面使用浅灰背景、白色卡片和单一蓝紫强调色，组件通过细边框与轻微阴影建立层次，避免大面积渐变和高饱和装饰。

## 视觉令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 背景 | #F5F5F7 | 应用工作区背景 |
| 表面 | #FFFFFF | 卡片、输入框和侧边栏 |
| 主色 | #5E5CE6 | 主按钮、当前导航和关键数据 |
| 正文 | #1D1D1F | 标题与正文 |
| 次要文字 | #6E6E73 | 辅助说明、时间和提示 |
| 分隔线 | #E5E5EA | 边框与分组边界 |

使用 8px 间距节奏；卡片圆角 16–18px，控件圆角 10–12px；正文至少 14px，关键数字使用等宽数字避免计时刷新时跳动。

## 交互与动效

- 页面切换使用 240ms 的水平滑入，方向与导航顺序一致，帮助用户保持空间连续性。
- 概览组件重新排序、显示隐藏或调整尺寸时，使用 260ms OutCubic 几何过渡；组件从原位置平滑移动到新网格位置，周围卡片同步推挤。
- 微交互保持 150–300ms，优先使用位置和透明度，避免突兀的瞬时变化。
- 窗口缩放时不启动布局动画，避免拖动窗口产生延迟。
- 后续接入系统“减少动态效果”偏好时，应将过渡时长降为 0–80ms，并保留状态变化本身。

## 组件约定

- 侧边栏是稳定的二级导航，当前页面同时通过文字、颜色和背景块标识。
- 所有按钮保留可见焦点、禁用态和至少 44px 的点击高度。
- 图标使用同一套线性图标；当前项目的文字操作按钮继续保持清晰标签，不使用 emoji 作为结构图标。
- 错误、成功和提醒状态同时提供文字，不依赖颜色单独传达含义。

## 维护方式

全局颜色、圆角和控件状态集中维护在 app/presentation/theme.py。布局动画位于 app/presentation/widgets.py，页面切换动画位于 app/presentation/window.py。新增页面或组件时先复用令牌，再记录本文件中的例外和原因。
