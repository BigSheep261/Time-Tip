# 文字阅读组件（待开发）

本轮优先交付项目分层、循环倒计时、覆盖安装和单实例运行。阅读组件尚未加入界面或打包依赖。

后续建议范围：

- 首批支持 `.txt`、`.docx`、`.epub`，导入后展示目录与正文，保存每本书的阅读进度。
- Word `.doc` 属于旧格式，需独立转换方案；不与 `.docx` 混为同一解析器。
- 领域层定义书籍、章节与阅读位置；应用层处理导入及进度；基础设施层为各格式提供解析器；表现层提供阅读页和概览入口。
- EPUB/Word 中的图片、复杂排版、书签和搜索放在后续迭代；解析不执行文档中的脚本或宏。

导入文件默认保留原件，阅读进度沿用当前本机配置策略。具体排版、内容库位置和导入体验待阅读功能启动时确定。
