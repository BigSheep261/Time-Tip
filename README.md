# TimeTip

TimeTip 是一个仅供个人使用的 Windows 桌面时间管理工具，使用 PyQt6 开发。它采用无边框苹果风格界面，数据保存在当前 Windows 用户的本机设置中。

## 功能

- 多个独立倒计时：支持名称、目标日期时间、编辑、删除和独立到期提醒
- 倒计时分为标准倒计时与循环倒计时；循环支持每天、周一至周五、每周自选日期及跨天时段
- 显示当前时间和星期
- 多条备忘录：独立标题和正文、自动保存、切换时保存、删除后撤销
- 概览小组件：支持 1×1、2×1、2×2、4×1、4×2，自定义大小、顺序、显示或隐藏
- 每日工资：输入月薪、每周工作日、上下班及可选午休时间，每秒更新已赚金额
- 番茄钟：可配置专注和休息时长
- 日历提醒：为指定日期与时间添加、查看、删除提醒；可选择需要电脑提醒或仅在日历显示
- 无边框窗口、边缘及四角拖动缩放、最大化 / 还原、双击标题栏、记住窗口尺寸和位置
- 看番提醒：记录番剧名称、放送开始/结束日期、每周放送日、总集数、观看进度、分类和本地文件夹；自动计算每一话日期并标记日历
- 概览日期格式可选中文完整、中文紧凑、ISO 日期、日式“火曜日”或同时显示星期和曜日
- 关闭窗口后在系统托盘继续运行；右键托盘图标可显示窗口或退出
- 单实例运行：重复启动只会唤醒已有窗口
- 设置中可开关开机自启（写入当前 Windows 用户的启动项，无需管理员权限）

## 安装与使用

双击项目目录中的 `TimeTip-Setup.exe`，会自动安装到当前用户的 `%LOCALAPPDATA%\TimeTip`，创建桌面快捷方式并启动。无需预装 Python，无需管理员权限。适用于 Windows 10/11 64 位。

“倒计时”页中选择标准或循环类型。标准倒计时到达目标后提醒一次并停在零；循环倒计时按周期内的开始/结束时间运行。例如每天 09:30–17:30：09:30 前显示“待开始”和完整 8 小时，09:30 起倒数，17:30 提醒并等待次日 09:30。可选每天、周一至周五或每周指定日期；结束时间早于开始时间表示跨天，所选星期按开始日期计算。选中已有条目可编辑或删除。“设置”页显示进行中、待开始和已结束的数量，每条倒计时也会默认出现在“概览”中。删除后可在当前会话撤销最近一次删除。

在“概览”点击“编辑布局”，再点组件右上角的 `···`，可调整宽 × 高、前后顺序或隐藏。也可以在“设置 → 概览组件”中统一设置大小和显示状态。宽窗口使用 4 列，窄窗口自动排为 2 列；内容较多时垂直滚动，保存的组件尺寸不会被窄窗口覆盖。窗口最小为 860×620，可拖动边缘、四角或概览右下角的缩放手柄调整。

在“设置”中勾选“开机自动启动 TimeTip”即可让程序在当前 Windows 用户登录后自动运行；取消勾选会移除启动项。

在“设置 → 每日工资”填写月薪、工作日、上下班时间和可选午休时间，保存后在概览查看。计算方式为：`每日工资 = 月薪 ÷ 当月勾选的工作日数`，`当前已赚 = 每日工资 × 已经过的有效工作秒数 ÷ 每日有效工作总秒数`。上班期间每秒刷新，下班、午休和休息日不增长，下班后保留当天已赚金额，下一天重新计算。程序重启或休眠恢复会按已经过的工作时段重新计算，不依赖程序保持前台运行。

工资支持跨午夜班次，按班次开始日期及其月份计算；跨日后会显示所属班次日期。每周工作日由用户勾选，法定节假日和调休暂不自动识别。当前设置会用于重新计算当前班次，工资金额是按设置推算的数值。

“看番提醒”页通过非模态编辑窗口编辑番剧，窗口打开时仍可继续使用主界面。填写放送开始和结束日期、每周星期、总集数后，程序会按每周一集计算全部集数的日期，不需要输入小时分钟。观看进度使用“− / ＋”按钮调整，分类可选补番、追番或已看完；封面可上传，未上传时使用默认封面。可选关联本地视频文件夹。番剧在对应日期出现在日历中，只做日历标记，不会弹出电脑通知；概览的“番剧更新”组件只列出当天更新的番剧名称和进度。

日历提醒新增“需要电脑提醒”和“仅在日历显示”两种模式；旧数据默认按需要电脑提醒处理。设置页的“概览日期格式”会立即更新概览标题，可选择中文星期或日式星期名称。

“备忘录”页点击“新建备忘录”，可记录多条独立内容；输入后 0.5 秒自动保存，切换记录、关闭窗口和退出时也会保存。每条记录默认以独立组件出现在概览。日历页可为选中日期设置提醒时间；番茄钟支持开始、暂停、重置和专注/休息自动切换。

提醒需要程序运行，可保持在托盘中。电脑休眠或程序退出期间的提醒会在恢复运行后补发，已提醒的事项不会再次弹出；循环倒计时错过多轮时只补发最近一轮，随后继续当前或下一轮。新建或修改循环周期不会补发设置之前的提醒，单独修改标题也不会重复提醒。所有时间均以电脑本地时间为准。设置、倒计时、提醒、番剧和备忘录保存在安装目录下的 `data\timetip.sqlite3`；封面保存在 `data\covers`。设置页可导出为 JSON/ZIP 数据包，也可导入恢复。升级不会覆盖 `data` 目录。

升级会自动将旧版单条倒计时、通知状态和备忘录迁移为新列表，旧倒计时按标准类型加载。安装包校验完整性后关闭已安装的旧进程，将程序及运行库覆盖到同一目录；替换失败会尝试恢复旧文件。设置、备忘录和组件布局保留，不必先卸载。新版退出时先保存待写入数据；老版本不支持退出通信时，安装器会先关闭窗口触发保存，再结束仍驻留的旧进程。

正常启动只保留一个当前用户的 TimeTip 实例。重复点击快捷方式会恢复已有窗口；源码入口和安装版使用同一实例标识。安装后使用目录形式的运行库，避免单文件解包启动器额外常驻一个进程。

卸载时先在托盘右键退出，再删除安装目录和桌面快捷方式即可；数据会保留。

## 构建一键安装包

在 Windows PowerShell 中运行：

```powershell
python -m pip install -r requirements-dev.txt
.\build_installer.ps1
```

也可以直接双击项目目录中的 `build.bat` 或 `打包安装包.bat` 一键构建。脚本优先使用项目 `.venv` 内的 Python，其次使用 PATH 中的 Python；首次构建需先安装上述开发依赖。需要 Windows 10/11 64 位和 .NET Framework 4.x（安装器使用系统自带的 C# 编译器）。

脚本运行测试、构建程序、编译安装器，并在独立目录中验证安装和升级后生成 `TimeTip-Setup.exe`。双击它即可安装到 `%LOCALAPPDATA%\TimeTip`，并创建桌面快捷方式。`dist\TimeTip` 是完整便携目录；不能仅复制其中的 EXE，需连同 `_internal` 一起复制。

直接运行源码：

```powershell
python -m pip install -r requirements.txt
python timetip.py
```

验证：`python -m unittest discover -s tests -v`。覆盖数据迁移、循环边界、跨天、补提醒、重启保存、并发启动、实例崩溃恢复，以及原有功能。六个页面在宽窄窗口下的截图保存在 `screenshots` 目录。构建后的安装与运行集成检查也可单独执行 `python tests/verify_package.py`。

可运行 `python tests/preview_app.py` 打开独立样例工作台，其数据保存在 `build/ui-preview.ini`，用于手动检查 Windows 缩放和组件交互，不会修改正式用户配置。
